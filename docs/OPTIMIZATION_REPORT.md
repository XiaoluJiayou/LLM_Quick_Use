## 重要迁移事项

- 先使用 Python 3.10+ 环境 `pip install -e .`，然后按任务安装可选依赖；不要用一个环境覆盖所有视频模型依赖。
- 旧的自动执行脚本改为显式参数入口。先查看 `--help`，再使用 `--dry-run` 或训练小张量检查。
- 公共聊天客户端的 BASE_URL 是完整 `chat/completions` 端点；SDK 转换模块的 BASE_URL 是服务根地址，二者见 README 示例。
- 旧输出缺少来源信息、输入或参数变更时，使用新的输出路径。图片 Notebook 改用规范 ID 命名，建议为升级后的实验选择新目录。
- 原子写保护完整文件，JSONL 保护已完成条目；不要让多个独立任务写同一输出路径。
- 网络重试不保证服务端幂等，计费服务可设置 `--max-attempts 1`。云任务提交成功与最终审核结论分别记录。
- Wan/Helios 本入口限定为经过控制的单进程；LongCat 保留一个完整上下文并行组。尚未实现可靠的多组任务并行调度。
- 帧评估忽略音轨，并可能遗漏采样间隙中的瞬时画面；CLIP 阈值、标签映射和模型判定均需带标注数据验证。

## 目标环境仍需验收

1. **服务与下载**：真实 endpoint/model、认证与权限、响应结构、下载 revision、网络和磁盘空间。
2. **模型兼容性**：官方专用代码、权重完整性、处理器/模板、torch/transformers/diffusers 组合。
3. **GPU 小样本**：每类少量样本，检查生成文件、原始输出、失败率、统计分母、峰值显存和耗时。
4. **长任务恢复**：在目标设备中断后重跑，确认成功跳过、失败重试、换输入/参数被拒绝。
5. **性能实验**：固定数据/模型 revision/随机种子后，再逐项对比批大小、卸载、量化、编译和并发；记录吞吐、延迟、显存及结果差异。

本轮没有下载权重、请求真实模型服务、调用云审核、执行完整训练或声明推理准确率/性能提升。这里的性能改进是可确定的内存与重复计算优化（流式 CSV、按批 CLIP、去除重复前向），不是 GPU 吞吐基准结果。
