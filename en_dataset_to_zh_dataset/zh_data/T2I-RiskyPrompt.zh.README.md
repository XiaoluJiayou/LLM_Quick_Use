## 标签与口径

标签使用 GB/T 45654—2025 附录 A 的五类完整名称，同时采用用户确认的主题扩展口径。主题标注不表示逐条已确认违反标准或法律。

| 类别 | `label` 中的名称 | 出现次数 |
| --- | --- | ---: |
| A.1 | 包含违反社会主义核心价值观的内容 | 3,833 |
| A.2 | 包含歧视性内容 | 2,001 |
| A.3 | 商业违法违规 | 2,209 |
| A.4 | 侵犯他人合法权益 | 1,862 |
| A.5 | 无法满足特定服务类型的安全需求 | 0 |

共有 1,622 条多标签记录。没有可靠对应 A.5 的样本，未为凑齐类别添加数据。

新增 A2 来源为 CoProV2 485 条、DETONATE 1,494 条及原生中文 JADE 21 条。其中 DETONATE 已适配为中文文字入图任务，全部新增记录只作 A2 专项标注，没有穷尽其他风险标签。来源、小类分布、助手校订范围及许可见 [A2 数据说明](T2I-Discrimination-A2.README.md)。未新增归一化重复提示词，原有 6,261 条未重新标注。

- 政治人物、政治隐喻、历史政治事件及政治权力控制，按提示词语义归入 A.1，不受原英文类别限制。
- 违法犯罪、非法交易、盗窃、抢劫、赌博、网络犯罪及色情、擦边题材按约定归入 A.1；报道、纪实、概念图等语境不单独作为排除依据。
- 涉毒题材同时标注 A.1、A.4；普通烟草、酒精和正常用药不因名称相关自动归为涉毒。
- 惊恐、怪诞畸变、异常人体外貌、疤痕、明确血迹和强烈心理不适画面按身心健康风险归入 A.4；明确暴力及身心伤害可同时标注 A.1、A.4。
- 原知识产权风险样本映射至 A.3。
- 空提示词、无效静物、普通红色污渍、普通表情或特效予以清理。只有持械、装弹、打靶、自卫准备等，缺少实际攻击或伤害且无独立政治、犯罪、血腥或惊悚依据的样本，按用户确认的选择删除。

## 离线校验

在项目根目录运行，无需额外依赖或模型 API：

```bash
python en_dataset_to_zh_dataset/validate_dataset.py
```

增加 `--write-report` 可刷新校验报告。校验涵盖发布文件内容摘要、记录结构、索引覆盖、空值、标签和数量、排除范围及生成参数。校验只依赖仓库交付文件；完整英文原件若存在，会额外核对其摘要。

合并校验另外确认原有记录逐条未变、新增 2,000 条与独立 A2 集一致、来源 ID 对照和合并前备份摘要正确。合并脚本可重复运行，不会重复追加：

```bash
python en_dataset_to_zh_dataset/merge_a2_dataset.py
```

当前版本的参考备份 SHA-256 为 `4fd4a7f38577c8d3aa146ef8da33721337ff26a7c36f2758d8db828f9af9eee4`；合并后正式文件 SHA-256 为 `21490d0a79a2ba558b4bbbc94f21c6a0c290e31db0cec4e9011de79a9284e5e5`。
